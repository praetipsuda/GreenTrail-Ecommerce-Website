# 🍃 GreenTail - E-Commerce & Admin Back-Office System

ระบบเว็บแอปพลิเคชันสำหรับจัดการร้านค้าออนไลน์และระบบบริหารจัดการหลังบ้าน (Admin Dashboard) ของ **GreenTail** ช่วยให้ผู้ดูแลระบบสามารถจัดการข้อมูลสินค้า ลูกค้า คำสั่งซื้อ และวิเคราะห์ ยอดขายได้อย่างมีประสิทธิภาพ

---



## ✨ คุณสมบัติหลัก (Features)

### 🔐 ระบบจัดการสิทธิ์และการเข้าสู่ระบบ (Authentication & Authorization)
* **Admin Access Control:** มีระบบตรวจสอบสิทธิ์การใช้งาน (`Role-Based Access Control`) บังคับเข้าสู่ระบบผ่าน `admin_login.php` ก่อนเข้าถึงหน้าผู้ดูแลระบบ

### 🛠️ ระบบหลังบ้านสำหรับผู้ดูแลระบบ (Admin Dashboard)
1. **📦 จัดการสินค้า (Manage Products):** เพิ่ม, แก้ไข, ลบ และเรียกดูรายการสินค้าในคลัง
2. **👥 จัดการลูกค้า (Manage Customers):** ตรวจสอบและแก้ไขข้อมูลสมาชิก/ลูกค้า
3. **🛒 จัดการออเดอร์ (Manage Orders):** ตรวจสอบสถานะคำสั่งซื้อและจัดการขั้นตอนการจัดส่ง
4. **📊 รายงานรายได้และยอดขายรายเดือน (Monthly Sales Report):** สรุปผลตอบแทน ยอดขายรวม และแนวโน้มประจำเดือน
5. **🏆 10 อันดับสินค้าขายดี (Top 10 Bestsellers):** สรุปอันดับสินค้าที่มียอดสั่งซื้อสูงสุด 10 อันดับแรก

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend:** HTML5, CSS3, Bootstrap 5, FontAwesome 6
* **Backend:** PHP (Session-based Authentication)
* **Database:** MySQL
